# Voice Profile Rubric

## Corpus selection

For every sample, record:

| Sample | Owner approved | Audience | Channel | Date | Representative | Exclusion risk |
|---|---|---|---|---|---|---|

Prefer several current samples across the intended channel range. Exclude ghostwritten, copied, translated, experimental, or obsolete material unless its status is known.

## Voice dimensions

Score only dimensions supported by evidence:

| Dimension | Low end | High end | Evidence | Confidence | Context exception |
|---|---|---|---|---|---|
| Formality | conversational | formal | | | |
| Directness | exploratory | decisive | | | |
| Warmth | detached | warm | | | |
| Density | spacious | information-dense | | | |
| Energy | restrained | energetic | | | |
| Humor | literal | playful | | | |
| Authority | peer | expert | | | |

Add dimensions only when they change writing decisions.

## Rule format

Write each rule as:

- **Prefer or avoid:**
- **Evidence:**
- **Applies when:**
- **Exception:**
- **Confidence:** high | medium | low
- **Example:** neutral input → on-voice output

Include vocabulary, sentence construction, paragraph rhythm, evidence style, CTA intensity, and reader address only when recurring.

## Validation

1. Hold back one or more approved samples from profile extraction.
2. Transform neutral copy without changing claims or intent.
3. Compare the result with held-out samples for stance, vocabulary, rhythm, and reader relationship.
4. Flag mimicry, exaggeration, generic marketing language, factual drift, and channel mismatch.
5. Revise the smallest rule responsible for the mismatch.

## Do and do not table

| Do | Because | Do not | Failure caused |
|---|---|---|---|

Keep the table operational. Avoid abstract labels such as “authentic,” “premium,” or “engaging” unless a concrete writing behavior defines them.
